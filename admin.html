Backups Automáticos & Deploy GitHub Pages

👉 Publicar no GitHub Pages com os seus jogos:
  1. Clique no botão "Exportar p/ Deploy (jogos.json)" acima — irá baixar um arquivo jogos.json com todos os seus jogos cadastrados.
  2. Substitua o arquivo original na pasta data/jogos.json pelo que acabou de baixar.
  3. Faça commit e push das alterações para o repositório do GitHub.
  4. Aguarde 1-2 minutos o GitHub Pages atualizar. Ao abrir o site, os seus jogos serão carregados automaticamente e salvos no localStorage de quem acessar.
Segurança dos seus dados:

Sempre que você editar, adicionar, excluir ou restaurar os jogos, um snapshot automático é salvo aqui (até os últimos 10). Você pode restaurar qualquer um deles a qualquer momento.
